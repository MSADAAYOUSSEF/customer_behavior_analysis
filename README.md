# Customer Behavior Data Analysis

An end-to-end **Data Analytics portfolio project** focused on understanding customer shopping behavior and turning raw data into useful business insights.

The project covers the main steps of a real-world data analysis process: **data cleaning, exploratory analysis, SQL analysis and dashboard development.

---

## Project Goal

The main objective is to analyze customer shopping data and answer important business questions such as:

- Who are the most valuable customers?
- Which products generate the most sales?
- How do different customer groups behave?
- What factors influence purchasing decisions?
- How loyal are customers?
- Which areas could help improve business performance?

The project follows a complete workflow:

**Raw Data → Python → SQL → Power BI → Business Insights**

---

## Project Workflow

The project is divided into several stages:

### 1. Data Preparation with Python

The raw dataset is first explored and prepared for analysis.

Main tasks include:

- Importing the dataset
- Understanding the data structure
- Checking missing values
- Identifying duplicates
- Fixing data types
- Cleaning inconsistent values
- Creating useful columns
- Performing exploratory data analysis (EDA)

---

### 2. Data Analysis with SQL

After cleaning the data, it is stored in a SQL database for deeper analysis.

The SQL part focuses on answering business-related questions using queries.

Examples include:

- Customer segmentation
- Customer spending analysis
- Purchase frequency
- Product performance
- Sales by category
- Customer loyalty
- Average purchase value
- Comparison between customer groups

The project can be implemented using:

- MySQL
- PostgreSQL
- Microsoft SQL Server

---

### 3. Power BI Dashboard

The cleaned and analyzed data is then connected to **Power BI** to create an interactive dashboard.

The dashboard provides an easy way for users and business stakeholders to explore the results.

It includes information such as:

- Total sales
- Number of customers
- Average purchase amount
- Product performance
- Customer segments
- Sales trends
- Purchase behavior

Users can interact with the dashboard using filters and different visualizations.

---

### 4. Business Insights

The analysis is not limited to numbers and charts.

The final objective is to understand **what the data means for the business**.

The project identifies:

- Important customer groups
- High-performing products
- Purchasing patterns
- Potential areas for improvement
- Customer loyalty patterns
- Opportunities to increase sales and customer engagement
